# 🗳️ Online Voting System (C++)

## Project Description
This is a simple console-based Online Voting System developed in C++.  
It allows voter registration, candidate management, secure voting, and result counting using file handling.

## Features
- Candidate registration (Admin)
- Voter registration
- One person, one vote system
- Secure voting using CNIC/ID
- Vote counting
- Result display
- File-based data storage

## Concepts Used
- C++ OOP
- Structures (struct)
- File handling (fstream)
- Vectors
- Menu-driven system
- Data persistence

## Files
- `candidates.txt` → candidate data  
- `voters.txt` → voter records  
- `votes.txt` → vote records  

## Purpose
This project demonstrates a real-world simulation of an online voting system using C++ and basic data structures.
