# Advanced Online Voting System (C++)

## Overview
This project is an advanced, file-based Online Voting System developed in C++.  
It simulates a real-world election environment using role-based access (Admin and Voter) without password complexity, focusing on system logic, structure, and architecture.

---

## System Roles

### Admin
- Add and remove candidates
- View registered voters
- Monitor election results
- Reset election data
- Maintain system logs

### Voter
- Register as a voter
- Vote using unique CNIC/ID
- One-person-one-vote enforcement
- View election results
---

## Core Features
- Role-based system (Admin / Voter)
- One vote per voter
- CNIC/ID based identity system
- Persistent data storage
- Voting logs and audit trail
- File-based database
- Modular system design
- Clean architecture
- Data validation
---

## Technical Implementation
- Object-Oriented Programming (OOP)
- File handling (fstream)
- Data structures (struct, vector)
- Menu-driven architecture
- System logging
- Persistent storage system
---

## File Structure
- `candidates.txt` → candidate records  
- `voters.txt` → voter records  
- `votes.txt` → vote data  
- `logs.txt` → system logs  
---

## Purpose
This project demonstrates real-world system simulation, structured software design, and backend logic implementation in C++ without external databases or authentication systems.
